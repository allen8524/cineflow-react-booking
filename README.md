# CineFlow 영화 예매 웹 애플리케이션

CineFlow는 영화 탐색, 상영 시간 선택, 좌석 예매, 결제, 예매내역 조회, 관리자 예매 관리를 하나의 흐름으로 제공하는 React 기반 영화 예매 웹 애플리케이션입니다.

## 1. 프로젝트 개요

이 프로젝트는 영화 예매 서비스의 핵심 사용자 흐름과 관리자 흐름을 프론트엔드에서 구현한 기말 프로젝트입니다.

주요 목표는 다음과 같습니다.

- TMDB API를 활용한 실제 영화 데이터 표시
- 영화 목록, 상세, 빠른예매, 결제, 예매 완료 흐름 구현
- 상영 시간표, 좌석, 잔여석, 예매내역 데이터 연동
- 관리자 페이지에서 예매 현황 확인 및 취소 처리
- React Router 기반 페이지 이동과 Context API 기반 전역 상태 관리

## 2. 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| Frontend | React, TypeScript |
| Build Tool | Vite |
| Routing | React Router DOM |
| State Management | Context API, LocalStorage |
| External API | TMDB API |
| Styling | CSS |
| Code Quality | ESLint |
| CI | GitHub Actions |

## 3. 실행 전 준비 사항

Node.js와 npm이 설치되어 있어야 합니다.

권장 환경:

```text
Node.js 20 이상
npm 10 이상
```

TMDB API를 사용하려면 프로젝트 루트에 `.env` 파일을 만들고 아래 값 중 하나를 입력합니다.

```env
VITE_TMDB_ACCESS_TOKEN=발급받은_TMDB_ACCESS_TOKEN
```

또는

```env
VITE_TMDB_API_KEY=발급받은_TMDB_API_KEY
```

API 키가 없어도 프로젝트는 실행됩니다. 이 경우 기본 영화 데이터가 fallback으로 표시됩니다.

개발 서버 실행 후 브라우저에서 Vite가 안내하는 주소로 접속합니다.

일반적으로 아래 주소에서 확인할 수 있습니다.


## 5. 빌드 및 점검 방법

```bash
npm run lint
npm run build
npm run preview
```

각 명령어의 역할은 다음과 같습니다.

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run lint` | ESLint 기준 코드 점검 |

## 7. 주요 기능

### 7.1 영화 기능

- TMDB API 기반 현재 상영작 및 개봉 예정작 조회
- 영화 목록 페이지 제공
- 영화 상세 페이지 제공
- 영화명, 장르, 줄거리, 등급, 상영 상태 기반 검색
- 인기도, 평점, 개봉일, 러닝타임, 관람등급 표시
- API 호출 실패 시 기본 영화 데이터 fallback 처리

### 7.2 예매 기능

- 빠른예매 페이지 제공
- 영화 선택
- 상영 시간 선택
- 관람 인원 선택
- 좌석 선택
- 좌석 타입별 가격 차등 적용
- 결제 수단 선택
- 예매 완료 화면 제공
- 결제 완료 후 예매 선택값 초기화
- 결제 페이지 직접 접근 방지

### 7.3 시간표 및 좌석 기능

- TMDB에서 가져온 상영중 영화 기준 동적 시간표 생성
- 현재 날짜 기준 미래 상영 시간 자동 배치
- 상영관 타입별 가격 자동 설정
- 시간표별 예매석 및 잔여석 계산
- 예매 완료 좌석 중복 선택 방지
- 관리자 취소 처리 시 좌석 및 잔여석 복구

### 7.4 예매내역 기능

- 예매번호, 영화명, 예매자 정보 기반 조회
- 예매 상태별 필터링
- 예매 취소 처리
- 예매별 취소 사유 관리

### 7.5 관리자 기능

- 관리자 대시보드 제공
- 전체 영화 수, 시간표 수, 예매 완료 건수, 예상 매출 표시
- 영화 목록 조회
- 동적 생성 시간표 조회
- 시간표별 예매석 및 잔여석 확인
- 예매 목록 조회
- 관리자 예매 취소 처리

### 7.6 기타 기능

- 고객센터 및 FAQ 페이지 제공
- 잘못된 경로 접근 시 오류 페이지 제공
- GitHub Actions 기반 lint/build 자동 검증

## 9. 데이터 흐름

### 9.1 영화 데이터

1. 앱 실행 시 TMDB API 호출
2. `/movie/now_playing`, `/movie/upcoming` 응답 기반 영화 목록 생성
3. 각 영화는 `/movie/{id}` 상세 API를 추가 호출해 장르, 러닝타임, 관람등급, 이미지 정보를 보강
4. API 호출 실패 또는 API 키 미설정 시 로컬 기본 영화 데이터 사용

### 9.2 시간표 데이터

1. 영화 목록 중 `NOW_SHOWING` 상태이고 예매 가능한 영화만 추출
2. 최대 12개 영화에 대해 동적 시간표 생성
3. 앞쪽 6개 영화는 영화당 3개, 이후 영화는 영화당 2개 시간표 생성
4. 현재 날짜 기준 미래 날짜로 상영 시간 자동 배치
5. 상영관 타입에 따라 가격 자동 설정

### 9.3 예매 데이터

1. 사용자가 영화, 시간표, 인원, 좌석을 선택
2. 결제 완료 시 예매 데이터 생성
3. 예매 데이터는 LocalStorage에 저장
4. 좌석도와 잔여석 계산에 예매 데이터 반영
5. 예매 취소 시 해당 좌석과 잔여석 복구

## 11. 주요 폴더 구조

```text
src/
  components/        재사용 UI 컴포넌트
  context/           예매 흐름과 사용자 상태 관리
  data/              기본 영화, 상영관, 좌석, 예매 샘플 데이터
  pages/             라우트 단위 페이지
  services/          TMDB API 연동 로직
  types/             TypeScript 타입 정의
  utils/             포맷팅 및 시간표 생성 유틸 함수
```

주요 파일은 다음과 같습니다.

| 파일 | 설명 |
| --- | --- |
| `src/context/BookingContext.tsx` | 영화, 시간표, 예매, 로그인 상태 관리 |
| `src/services/tmdb.ts` | TMDB API 호출 및 영화 데이터 변환 |
| `src/utils/scheduleFactory.ts` | 영화 데이터 기반 동적 시간표 생성 |
| `src/data/seats.ts` | 좌석 생성, 좌석 타입, 좌석 가격 계산 |
| `src/pages/BookingPage.tsx` | 빠른예매 화면 |
| `src/pages/PaymentPage.tsx` | 결제 화면 |
| `src/pages/HistoryPage.tsx` | 예매내역 화면 |
| `src/pages/AdminPage.tsx` | 관리자 화면 |

## 13. 문제 해결

### 13.1 `vite` 명령어를 찾을 수 없는 경우

의존성이 설치되지 않은 상태입니다.

```bash
npm install
npm run dev
```

### 13.2 TMDB 영화가 나오지 않는 경우

`.env` 파일에 TMDB 키가 있는지 확인합니다.

```env
VITE_TMDB_ACCESS_TOKEN=발급받은_TMDB_ACCESS_TOKEN
```

API 키가 없거나 호출에 실패하면 기본 영화 데이터가 표시됩니다.

### 13.3 이전 예매 데이터가 화면에 남아 있는 경우

이 프로젝트는 LocalStorage를 사용합니다. 테스트 중 데이터가 꼬인 경우 브라우저 개발자 도구에서 아래 key를 삭제하면 됩니다.

```text
cineflow-bookings
cineflow-draft
cineflow-accounts
cineflow-current-user-id
```

또는 브라우저 사이트 데이터 삭제 후 새로고침합니다.

- 관리자 권한 검증
